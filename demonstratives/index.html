지시대명사 これ・それ・あれ・どれ

이것·그것·저것·어느 것을 일본어로 · 한자 위에 읽는 법이 있어요 · 끝에 문제 9개

1지시대명사 익히기 (こ·そ·あ·ど)

누르면 소리가 나와요. 노란 형광펜이 지시어예요. 가로로 보면 こ·そ·あ·ど가 한 세트예요.

알아 두면 좋아요
· こ = 말하는 나에게 가까운 것, そ = 듣는 상대에게 가까운 것, あ = 둘 다에게서 먼 것, ど = 물어볼 때.
· 「これ·それ·あれ」는 혼자 쓰고, 「この·その·あの」는 꼭 뒤에 명사가 와요. (✕ このは → ○ この{本|ほん}は)
· 가게나 회사에서는 「ここ」 대신 「こちら」를 쓰면 공손해요. 예: こちらへどうぞ (이쪽으로 오세요)

2문장 만들기

아래 단어 카드를 순서대로 눌러 문장을 만들어요. 지시어 카드에는 정답이 아닌 것도 섞여 있고, 단어·조사는 문장에 쓰는 것만 있어요. 놓은 카드를 다시 누르면 빠져요.

3일본어로 써 보기

단어 카드를 참고해서 일본어로 직접 써요. 마우스나 손가락으로 칸에 쓰거나, 키보드로 입력해도 돼요. 칸이 모자라면 ＋ 칸 추가, 다 썼으면 💾 저장 — 저장한 답은 문제 위쪽에 차곡차곡 쌓여요. 오른쪽 창에서 한자 획순을 볼 수 있어요. 정답은 나오지 않아요.
